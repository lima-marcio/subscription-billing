# Workflow

## Git

- Initialize a Git repository before writing application code.
- Generate a `.gitignore` appropriate for every technology used in the repository.
- For full-stack projects, create a single root `.gitignore` covering both backend and frontend artifacts.
- Never commit secrets, credentials, certificates, or environment-specific files.
- Commit messages follow Conventional Commits.
- No co-author line in commit messages.
- Keep commits focused on a single logical change.
